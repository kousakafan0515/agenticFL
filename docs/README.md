# 项目文档导航

这里放跨阶段、面向协作者的项目级文档。阶段自身的实验方案、运行说明和结果报告仍留在各阶段目录中。

| 文件 | 用途 | 更新时机 |
|---|---|---|
| [`PROJECT_MAP.md`](PROJECT_MAP.md) | 人类可读的目录地图、权威入口和编辑边界 | 目录职责或主入口变化时 |
| [`collaboration/NOW.md`](collaboration/NOW.md) | 当前任务的实时状态与 agent 接手点 | 每次任务开始、关键进展、暂停或完成时 |
| [`collaboration/DECISIONS.md`](collaboration/DECISIONS.md) | 稳定的跨会话决策记录 | 架构、实验口径或数据边界确定/改变时 |
| [`collaboration/SESSION_TEMPLATE.md`](collaboration/SESSION_TEMPLATE.md) | 新对话开场与交接模板 | 模板本身需要改进时 |

项目级 agent 行为规则见根目录 [`AGENTS.md`](../AGENTS.md)。
