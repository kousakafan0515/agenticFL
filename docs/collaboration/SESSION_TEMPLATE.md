# 新对话与交接模板

本模板供 agent 在新对话开场、阶段性汇报和暂停交接时复用。实际状态仍写入 `NOW.md`。

## 新对话开场

```text
本次目标：<一句话>
当前状态：<从 NOW.md 与相关阶段文档确认的事实>
工作范围：<准备读取/修改/验证的目录或文件>
计划：<2–4 个短步骤>
风险或假设：<没有则写“暂无”>
```

## 实时交接

```text
状态：待开始 / 进行中 / 等待用户 / 受阻 / 已完成待归档
负责人：<agent 或人员标识>
最后更新：YYYY-MM-DD HH:mm（Asia/Shanghai）
目标：<本任务要达成的可验证结果>
范围：<允许修改的目录；明确不修改什么>

已完成：
- <可核验事实>

下一步：
1. <最自然的第一步>

阻塞：
- <需要谁提供什么；没有则写“无”>

验证：
- <命令/检查及结果；未运行则写原因>

关键文件：
- `<path>`：<作用>

不要做：
- <容易误操作的事项>
```

## 完成回复

```text
结果：<先说是否完成及核心变化>
关键文件：<入口文件及作用>
验证：<运行了什么、结果如何>
遗留项：<没有则省略>
```
